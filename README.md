# Nerampokku Creations

Premium cinematic React + Vite website starter based on the supplied Nerampokku Creations creative brief.

## Run locally

1. Install Node.js 18+.
2. Extract this ZIP.
3. Open a terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL shown by Vite.

## Build for production

`npm run build`

Then deploy the generated `dist` folder to a static host.

## Replace placeholders

- Replace Unsplash image URLs in `src/main.jsx` with your own artwork/photos.
- Replace `hello@nerampokku.com` with the real contact email.
- Add the real YouTube/Instagram/Facebook URLs.
- Connect the music player to the actual audio/YouTube source.
